# Canonical sources and collection views (Increment 02)

## One source, many views

Every publishable example is a Hugo leaf bundle in `content/sources/<slug>/index.md`. Its Markdown and front matter are the sole canonical copy. Editing any index, grid, homepage or collection view must never require copying the content.

```yaml
---
title: "A research inquiry"
description: "Short summary"
date: 2026-11-07
kind: research
collections: [research, selected-work]
tags: [methods]
featured: true
weight: 1
---
```

- `kind` is freely chosen presentation metadata, not a required academic discipline or Hugo `type`.
- `collections` is a **Hugo taxonomy**; each value yields a term under `/collections/<term>/`. A source may belong to several terms.
- `tags` is a separate descriptive taxonomy; the two are intentionally not interchangeable.
- `featured` includes the source on the homepage.
- `weight` sorts entries in indexes (smallest first); collisions should be avoided if explicit order matters.
- `draft: true` excludes a source from production builds while `hugo server -D` includes it.

## Routing

Source files stay below `content/sources/`. The configured permalink rule maps source leaf pages to `/work/<slug>/`. In Hugo, the **sources index** stays at `/sources/`; it is not the same as `/work/`. Collection landing pages are generated by Hugo at `/collections/` and individual terms at `/collections/<term>/`.

The layout uses `.RelPermalink`, not hand-built URLs, so alternative hostnames and subpaths remain feasible.

## Presentation views

The listing and grid buttons are **progressive enhancement**: both views render the same server-generated HTML. Without JavaScript, the default list remains accessible. With JavaScript, `?view=grid` selects grid styling and the URL reflects the selection. No duplicate data, API, or extra Markdown files are generated.

## Known constraints

- Collection terms are **taxonomy groups**, not ordered, individually curated reading lists. The first release uses `weight` and Hugo taxonomy membership. Custom curator ordering or introductions can be considered separately.
- The generic collection index and term pages work with the current Markdown schema. A book/chapter structure is reserved for Increment 04.
- Only leaf sources are canonical content at this stage; taxonomy pages and site chrome are derived navigation or metadata.
- Filtering/sorting beyond `weight`, such as complex OR conditions and combined facets, is out of scope for this increment.
