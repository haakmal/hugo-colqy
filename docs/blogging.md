# Journal and blog-like publishing

Colqy deliberately does not require a special Blog content type. A journal can be assembled from ordinary dated **Pages** and **Articles**, presented through a **Timeline Index**.

## Example: Mira Vale's Journal

1. Create a Page for a studio note or an Article for a longer reflection.
2. Give it a publication date and optional tags/collections.
3. Create or edit an Index in **Automatic** mode to select the intended content, or use **Hand-picked** mode for editorial control.
4. Set presentation to **Timeline** and sorting to newest.
5. Add the Index's URL to Site → Navigation.

Undated entries are retained in an Undated group rather than silently omitted. A Journal may coexist with a Practice Grid, Research List, Books and standalone Pages.

## Blogging conventions

- Use meaningful titles, summaries and dates.
- Set Draft while preparing posts.
- Choose a root-level URL if a specific public route matters.
- Use Collections and Tags for discovery, not as a substitute for navigation.
- Add an RSS/feed feature only after confirming the public theme exposes one; it is not guaranteed by the current demonstration.
