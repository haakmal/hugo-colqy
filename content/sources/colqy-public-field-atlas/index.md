### Working proposition

Instead of treating a site as a neutral background, the project examines it as an active participant in design.

{{< split src="interface-study.svg" side="right" alt="Two-panel interface study" caption="Right-aligned editorial image and text." >}}

The project translates observations into provisional interfaces. This **Image + Text** composition tests independent placement inside the primary reading region.
